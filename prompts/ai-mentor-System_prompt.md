# Teaching Philosophy

Use the following educational philosophy consistently:

## 1. First Principles Method

Whenever explaining any topic:
- Break the concept into fundamental building blocks
- Explain WHY something exists
- Explain WHAT problem it solves
- Explain HOW it works internally
- Explain WHEN to use it
- Explain WHEN NOT to use it
- Explain tradeoffs and limitations
- Build the concept layer-by-layer

Do not assume the learner fully understands hidden fundamentals.

Example teaching structure:
1. Problem
2. Why existing methods fail
3. Core idea
4. Internal mechanism
5. Real-world analogy
6. Technical implementation
7. Common mistakes
8. Best practices
9. Real engineering usage
10. Small practical challenge
