# Semester 6: Artificial Intelligence & Software Systems

## Artificial Intelligence and Machine Learning

### Overview
Study of artificial intelligence principles and machine learning algorithms. Covers search, knowledge representation, supervised/unsupervised learning, neural networks, and model evaluation.

### Learning Objectives
- Understand AI fundamentals: intelligent agents, problem-solving, search
- Implement supervised learning: regression, classification, decision trees, SVM, ensemble methods
- Implement unsupervised learning: clustering, dimensionality reduction
- Understand neural networks and deep learning basics
- Evaluate model performance using appropriate metrics and validation
- Apply ML to real-world problems

### Detailed Topics
- **Module 1:** AI Foundations: history, intelligent agents, problem types, Turing test, state-space search
- **Module 2:** Search Algorithms: BFS, DFS, uniform cost, A*, heuristic search, adversarial search (Minimax, alpha-beta pruning), constraint satisfaction
- **Module 3:** Knowledge Representation: logic, propositional logic, predicate logic, inference, reasoning under uncertainty (Bayesian networks)
- **Module 4:** Supervised Learning: linear regression, logistic regression, decision trees, random forests, SVM, k-NN, naive Bayes, ensemble methods (bagging, boosting, XGBoost)
- **Module 5:** Unsupervised Learning: k-means, hierarchical clustering, DBSCAN, PCA, t-SNE, association rules
- **Module 6:** Neural Networks: perceptron, MLP, backpropagation, activation functions, regularization
- **Module 7:** Deep Learning: CNNs, RNNs/LSTMs, transfer learning, introduction to transformers
- **Module 8:** Model Evaluation: cross-validation, bias-variance tradeoff, confusion matrix, precision/recall, ROC curve, hyperparameter tuning (GridSearch, RandomSearch)

## Database Management Systems

### Overview
Study of database management systems: relational model, SQL, database design, normalization, transaction management, and NoSQL databases.

### Learning Objectives
- Design relational databases using ER modeling and normalization
- Write complex SQL queries (joins, subqueries, aggregation, window functions)
- Understand query processing and optimization
- Manage transactions: ACID, concurrency control, recovery
- Understand NoSQL databases (MongoDB, Redis)
- Build database-backed applications

### Detailed Topics
- **Module 1:** DBMS Architecture: data models, schemas, instances, DBMS components
- **Module 2:** Relational Model: relations, keys, integrity constraints, relational algebra
- **Module 3:** SQL: DDL, DML, joins, subqueries, set operations, views, indexes
- **Module 4:** Advanced SQL: aggregation, window functions, CTEs, recursive queries, stored procedures
- **Module 5:** ER Modeling: entities, attributes, relationships, cardinality, ER-to-relational mapping
- **Module 6:** Normalization: functional dependencies, 1NF-5NF, BCNF, decomposition
- **Module 7:** Query Processing: parsing, optimization, join algorithms, cost estimation
- **Module 8:** Transaction Management: ACID, schedules, serializability, locking, 2PL, timestamp-based concurrency
- **Module 9:** Recovery: ARIES, logging, checkpoints, undo/redo
- **Module 10:** NoSQL: document databases (MongoDB), key-value (Redis), column-family (Cassandra), graph (Neo4j)

## Instrumentation and Control

### Overview
Study of instrumentation systems, sensors, transducers, and control systems. Covers measurement principles, signal conditioning, and feedback control.

### Learning Objectives
- Understand measurement principles and sensor characteristics
- Analyze instrumentation systems: sensors, signal conditioning, data acquisition
- Design and analyze control systems using block diagrams and transfer functions
- Understand PID control and controller tuning
- Apply control theory to real-world systems

### Detailed Topics
- **Module 1:** Instrumentation Fundamentals: measurement, accuracy, precision, resolution, sensitivity, linearity, calibration
- **Module 2:** Sensors and Transducers: temperature (RTD, thermocouple, thermistor), pressure, strain/force, displacement (LVDT), flow, level, light, accelerometer
- **Module 3:** Signal Conditioning: amplification, filtering, isolation, linearization, bridge circuits, analog-to-digital conversion (ADC)
- **Module 4:** Data Acquisition: DAQ systems, sampling, multiplexing, data logging, LabVIEW
- **Module 5:** Control Systems Basics: open-loop vs. closed-loop, feedback, block diagrams, transfer functions
- **Module 6:** Time-Domain Analysis: transient response, steady-state error, first/second-order systems, time-domain specifications
- **Module 7:** Stability Analysis: Routh-Hurwitz criterion, root locus
- **Module 8:** Frequency-Domain Analysis: Bode plots, Nyquist criterion, gain/phase margin
- **Module 9:** PID Control: proportional, integral, derivative control, controller tuning (Ziegler-Nichols), modifications
- **Module 10:** Applications: temperature control, motor speed control, level control, PLC basics

### Books

- **"Control Systems Engineering, 8th Edition"** by Norman S. Nise (Wiley, 2019)
- **"Measurement and Instrumentation: Theory and Application, 3rd Edition"** by Alan S. Morris and Reza Langari (Academic Press, 2020)

## Probability and Statistics

### Overview
Study of probability theory and statistical methods for engineering applications. Covers probability distributions, statistical inference, regression, and hypothesis testing.

### Learning Objectives
- Understand probability axioms, conditional probability, Bayes' theorem
- Apply probability distributions (discrete and continuous)
- Apply law of large numbers and central limit theorem
- Perform statistical inference: estimation, confidence intervals, hypothesis testing
- Apply linear regression and correlation analysis
- Use statistical software for data analysis

### Detailed Topics
- **Module 1:** Probability Foundations: sample space, events, axioms, counting, conditional probability, Bayes' theorem, independence
- **Module 2:** Random Variables: discrete/continuous, PMF, PDF, CDF, expectation, variance, moments
- **Module 3:** Discrete Distributions: Bernoulli, Binomial, Geometric, Poisson, Hypergeometric
- **Module 4:** Continuous Distributions: Uniform, Normal, Exponential, Gamma, Chi-squared, Student's t
- **Module 5:** Joint Distributions: joint PMF/PDF, marginal, conditional, independence, covariance, correlation
- **Module 6:** Limit Theorems: LLN, CLT, Markov/Chebyshev inequalities
- **Module 7:** Descriptive Statistics: data visualization, measures of central tendency, dispersion
- **Module 8:** Statistical Inference: point estimation (MLE), confidence intervals, sampling distributions
- **Module 9:** Hypothesis Testing: null/alternative, type I/II errors, p-value, Z-test, t-test, chi-squared test, ANOVA
- **Module 10:** Regression: simple linear regression, multiple regression, correlation, model diagnostics

### Books
- **"Introduction to Probability, 2nd Edition"** by Bertsekas and Tsitsiklis (Athena Scientific, 2008)
- **"Probability and Statistics for Engineers and Scientists, 9th Edition"** by Walpole, Myers, Myers, and Ye (Pearson, 2016)
- **"Statistical Inference, 2nd Edition"** by Casella and Berger (Cengage, 2001)
