# Semester 3: Object-Oriented & Digital Systems

## Object Oriented Programming (OOP in Java)

### Overview
Comprehensive study of object-oriented programming concepts using Java. Covers encapsulation, inheritance, polymorphism, abstraction, exception handling, generics, and collections framework.

### Learning Objectives
- Understand OOP principles: encapsulation, inheritance, polymorphism, abstraction
- Master Java syntax, JVM architecture, and memory management (garbage collection)
- Implement inheritance hierarchies, interfaces, and abstract classes
- Use Java Collections Framework, generics, and lambda expressions
- Handle exceptions and implement file I/O
- Develop GUI applications using JavaFX or Swing
- Apply design patterns and OOP best practices

### Detailed Topics
- **Module 1:** Java Fundamentals: JVM, JDK, JRE, bytecode, classpath, package structure, main method, primitive vs. reference types
- **Module 2:** Classes and Objects: constructors, instance vs. static members, this keyword, method overloading, access modifiers (public, private, protected, default)
- **Module 3:** Inheritance: extends, super, method overriding, final keyword, abstract classes, sealed classes (Java 17+)
- **Module 4:** Polymorphism: compile-time (overloading), runtime (overriding, dynamic dispatch), instanceof, downcasting
- **Module 5:** Interfaces: definition, implementing, default methods, static methods, functional interfaces, marker interfaces
- **Module 6:** Exception Handling: try-catch-finally, checked vs. unchecked exceptions, custom exceptions, try-with-resources
- **Module 7:** Java Collections Framework: List (ArrayList, LinkedList), Set (HashSet, TreeSet, LinkedHashSet), Map (HashMap, TreeMap, LinkedHashMap), Queue (PriorityQueue, Deque)
- **Module 8:** Generics: generic classes, methods, bounded type parameters, wildcards (? extends, ? super)
- **Module 9:** Lambda Expressions and Streams: functional interfaces, lambda syntax, Stream API (map, filter, reduce, collect), method references
- **Module 10:** File I/O and Serialization: java.io, java.nio, BufferedReader, Scanner, ObjectInputStream/ObjectOutputStream, NIO.2 (Path, Files)
- **Module 11:** GUI Programming: JavaFX (Scene, Stage, Controls, Layout, Events, FXML) or Swing basics
- **Module 12:** Multithreading: Thread class, Runnable, synchronized, wait/notify, ExecutorService, CompletableFuture

## Computer Aided Design (CAD)

### Overview
Introduction to computer-aided design and drafting. Covers 2D and 3D modeling techniques, engineering drawings, and design visualization using industry-standard CAD software.

### Learning Objectives
- Create 2D engineering drawings with proper dimensioning and annotations
- Develop 3D solid models using parametric modeling techniques
- Create assemblies and generate exploded views
- Generate engineering documentation (orthographic, isometric, section views)
- Understand CAD standards and file formats (DWG, DXF, STEP, IGES)
- Apply CAD in engineering design projects

### Detailed Topics
- **Module 1:** Introduction to CAD: history, applications, benefits, types (2D, 3D, parametric, direct modeling)
- **Module 2:** 2D Drafting: coordinate systems, drawing tools (line, circle, arc, polygon), editing tools (trim, extend, offset, mirror, array, fillet, chamfer)
- **Module 3:** Dimensioning and Annotations: linear, angular, radial, ordinate, geometric dimensioning and tolerancing (GD&T), text, hatching
- **Module 4:** Layers and Blocks: layer management, block definition, attributes, dynamic blocks, external references (Xref)
- **Module 5:** 3D Solid Modeling: extrusion, revolution, sweep, loft, boolean operations (union, subtract, intersect)
- **Module 6:** Parametric Modeling: constraints (geometric, dimensional), design intent, feature-based modeling
- **Module 7:** Assemblies: component placement, mates/constraints, interference detection, exploded views, bill of materials
- **Module 8:** Surface Modeling: extruded surfaces, revolved surfaces, swept surfaces, blended surfaces, boundary surfaces
- **Module 9:** Engineering Drawings: orthographic projection, section views, auxiliary views, isometric views, detail views
- **Module 10:** CAD Standards: layer naming, file naming, drawing templates, plotting/printing, file exchange formats

## Digital Logic Design

### Overview
Study of digital logic circuits, from Boolean algebra to sequential circuit design. Covers combinational and sequential logic, minimization techniques, and hardware description languages.

### Learning Objectives
- Understand Boolean algebra, logic gates, and minimization techniques
- Design and analyze combinational logic circuits (adders, multiplexers, decoders, encoders)
- Design and analyze sequential logic circuits (flip-flops, counters, registers, FSMs)
- Program PLDs and FPGAs using hardware description languages
- Implement digital systems using standard ICs and simulation tools
- Understand memory elements: ROM, RAM, CAM

### Detailed Topics
- **Module 1:** Number Systems and Codes: binary, octal, hexadecimal, BCD, Gray code, ASCII, error detection/correction (parity, Hamming code)
- **Module 2:** Boolean Algebra: axioms, theorems, De Morgan's laws, duality, canonical forms (SOP, POS), minterms, maxterms
- **Module 3:** Logic Gates: AND, OR, NOT, NAND, NOR, XOR, XNOR, universal gates, IC logic families (TTL, CMOS)
- **Module 4:** Boolean Minimization: Karnaugh maps (K-maps) 2-6 variables, Quine-McCluskey algorithm, don't care conditions
- **Module 5:** Combinational Logic: adders (half, full, ripple carry, carry look-ahead), subtractors, multiplexers, demultiplexers, decoders, encoders, priority encoders, comparators, ALU design
- **Module 6:** Sequential Logic Elements: SR latch, D latch, JK flip-flop, D flip-flop, T flip-flop, edge-triggered vs. level-sensitive, setup/hold time
- **Module 7:** Registers and Counters: shift registers (SIPO, PISO, SISO, PIPO), synchronous/asynchronous counters, up/down counters, ring counters, Johnson counters
- **Module 8:** Finite State Machines: Mealy vs. Moore machines, state diagrams, state tables, state assignment, state minimization, FSM implementation
- **Module 9:** Memory: ROM, PROM, EPROM, EEPROM, Flash, SRAM, DRAM, memory organization, timing, expansion
- **Module 10:** HDL and Programmable Logic: VHDL/Verilog basics, FPGA architecture, CPLD, synthesis, simulation testbenches

## Discrete Structures

### Overview
Study of discrete mathematical structures fundamental to computer science. Covers logic, set theory, combinatorics, graph theory, and algebraic structures.

### Learning Objectives
- Understand propositional and predicate logic, logical equivalences, and proofs
- Apply set theory, relations, and functions
- Solve counting problems using combinatorics and probability
- Analyze graphs, trees, and their applications
- Understand algebraic structures: groups, rings, fields
- Apply discrete mathematics in algorithm analysis, cryptography, and software engineering

### Detailed Topics
- **Module 1:** Propositional Logic: statements, connectives, truth tables, logical equivalences, De Morgan's laws, implications, contrapositive, converse, inverse
- **Module 2:** Predicate Logic: quantifiers, predicates, nested quantifiers, logical equivalences with quantifiers
- **Module 3:** Proof Techniques: direct proof, proof by contraposition, proof by contradiction, proof by induction (weak, strong), structural induction, counterexamples
- **Module 4:** Sets: sets, subsets, power sets, Cartesian product, set operations, Venn diagrams, set identities, cardinality
- **Module 5:** Relations: reflexive, symmetric, transitive, antisymmetric, equivalence relations, partial orders, Hasse diagrams, closures
- **Module 6:** Functions: injective, surjective, bijective, inverse, composition, floor/ceiling, growth of functions (big-O, big-Omega, big-Theta)
- **Module 7:** Combinatorics: counting principles (sum, product), permutations, combinations, binomial theorem, pigeonhole principle, inclusion-exclusion, recurrence relations
- **Module 8:** Graph Theory: graphs, directed/undirected, complete, bipartite, degree, adjacency matrix, Eulerian/Hamiltonian paths, planar graphs, graph coloring
- **Module 9:** Trees: rooted trees, binary trees, tree traversal, spanning trees, minimum spanning trees (Kruskal, Prim), Huffman coding
- **Module 10:** Algebraic Structures: groups, semigroups, monoids, rings, fields (introductory)

## Differential Equations

### Overview
Study of ordinary differential equations and their applications in engineering. Covers analytical solution techniques, numerical methods, and modeling of physical systems.

### Learning Objectives
- Classify and solve first-order ODEs (separable, linear, exact, Bernoulli)
- Solve higher-order linear ODEs with constant coefficients
- Apply Laplace transforms to solve ODEs and initial value problems
- Solve systems of linear ODEs using eigenvalue methods
- Understand numerical methods for ODEs (Euler, Runge-Kutta)
- Model real-world engineering systems using differential equations

### Detailed Topics
- **Module 1:** Introduction: classification of DEs, order, linearity, solutions, initial value problems
- **Module 2:** First-Order ODEs: separable, linear (integrating factor), exact, Bernoulli, substitution methods, applications (population growth, Newton's law of cooling, mixing problems, RC/RL circuits)
- **Module 3:** Higher-Order Linear ODEs: homogeneous equations, characteristic equations, method of undetermined coefficients, variation of parameters
- **Module 4:** Applications: mechanical vibrations (spring-mass-damper), LRC circuits, beam deflection
- **Module 5:** Laplace Transforms: definition, properties, inverse transforms, convolution, solving IVPs, step functions, Dirac delta
- **Module 6:** Systems of Linear ODEs: matrix form, eigenvalue method, phase portraits, stability analysis
- **Module 7:** Numerical Methods: Euler's method, improved Euler, Runge-Kutta (RK4), error analysis, stability
- **Module 8:** Series Solutions: power series method, Frobenius method, Bessel functions, Legendre polynomials

## Technical Writing

### Overview
Advanced course in technical writing for engineering and computer science. Covers documentation, technical reports, research papers, and professional communication.

### Learning Objectives
- Write clear, organized technical documents for various audiences
- Create effective technical documentation (user manuals, API docs, specifications)
- Write research papers following IEEE/ACM formatting
- Develop visual communication skills (diagrams, graphs, tables)
- Revise and edit documents for clarity, conciseness, and correctness
- Collaborate on technical writing projects using version control

### Detailed Topics
- **Module 1:** Technical Writing Process: planning, researching, drafting, revising, editing, proofreading
- **Module 2:** Document Structure: front matter, body, back matter, headings, sections, numbering
- **Module 3:** Technical Definitions and Descriptions: definitions, descriptions of mechanisms, descriptions of processes
