# Semester 2: Programming & Circuit Fundamentals

## Computer Programming (Intro to C++)

### Overview
Introduction to computer programming using C++. Covers fundamental programming concepts, procedural programming, and object-oriented basics. Emphasizes problem-solving, algorithm development, and structured programming techniques.

### Learning Objectives
- Understand the software development lifecycle: edit, compile, link, execute, debug
- Master C++ syntax: variables, data types, operators, expressions, control structures
- Implement functions, parameter passing, recursion, and scope rules
- Understand arrays, pointers, dynamic memory allocation, and strings
- Understand file I/O operations and exception handling
- Develop problem-solving skills through programming assignments
- Apply debugging techniques and use an IDE effectively

### Detailed Topics
- **Module 1:** Introduction to Programming: algorithms, flowcharts, pseudocode, programming paradigms
- **Module 2:** C++ Basics: program structure, headers, main function, I/O (cin, cout), comments, preprocessor directives
- **Module 3:** Variables and Data Types: int, float, double, char, bool, const, type casting, sizeof operator
- **Module 4:** Operators and Expressions: arithmetic, relational, logical, bitwise, assignment, increment/decrement, ternary, precedence
- **Module 5:** Control Structures: if, if-else, switch, while, do-while, for loops, break, continue, nested control structures
- **Module 6:** Functions: declaration, definition, parameters (pass by value/reference), return types, overloading, default arguments, inline functions, recursion
- **Module 7:** Arrays and Strings: 1D and 2D arrays, array initialization, pointer arithmetic, C-strings, string class (std::string), array of strings
- **Module 8:** Pointers and Dynamic Memory: pointer declaration, dereferencing, pointer arithmetic, new/delete operators, dynamic arrays, memory leaks, smart pointers (intro)
- **Module 9:** Structures and Unions: struct, union, typedef, enum, nested structures, passing structures to functions
- **Module 10:** File I/O: fstream, ifstream, ofstream, text vs. binary files, file open modes, error handling
- **Module 11:** Introduction to OOP: classes, objects, access specifiers, constructors, destructors, this pointer, static members

## Linear Circuit Analysis

### Overview
Fundamental course in electrical circuit analysis covering DC and AC circuits. Emphasizes analytical techniques, network theorems, and transient analysis for linear circuits.

### Learning Objectives
- Understand basic circuit concepts: voltage, current, power, energy, resistance
- Apply Ohm's law, Kirchhoff's laws, and circuit reduction techniques
- Analyze circuits using nodal and mesh analysis
- Apply network theorems: Thevenin, Norton, superposition, maximum power transfer
- Analyze first-order RL and RC circuits (transient response)
- Understand AC steady-state analysis using phasors
- Measure and verify circuit parameters using laboratory equipment

### Detailed Topics
- **Module 1:** Basic Concepts: SI units, charge, current, voltage, power, energy, passive sign convention
- **Module 2:** Resistive Circuits: Ohm's law, Kirchhoff's current/voltage laws (KCL/KVL), series/parallel combinations, voltage/current division
- **Module 3:** Nodal and Mesh Analysis: nodal analysis with/without voltage sources, mesh analysis with/without current sources
- **Module 4:** Network Theorems: superposition, Thevenin's theorem, Norton's theorem, maximum power transfer, source transformation, reciprocity
- **Module 5:** Operational Amplifiers: ideal op-amp model, inverting/non-inverting amplifier, summing amplifier, difference amplifier, integrator, differentiator
- **Module 6:** Capacitors and Inductors: I-V relationships, series/parallel combinations, energy storage
- **Module 7:** First-Order Circuits: RC and RL circuits, natural response, step response, time constant
- **Module 8:** Second-Order Circuits: RLC circuits, natural response (overdamped, critically damped, underdamped), step response
- **Module 9:** Sinusoidal Steady-State Analysis: phasors, impedance, admittance, complex frequency, AC circuit analysis
- **Module 10:** AC Power Analysis: instantaneous power, average power, RMS value, apparent power, power factor, complex power, maximum power transfer in AC

## Electronic Devices and Circuits

### Overview
Study of semiconductor devices: diodes, transistors, and their applications in electronic circuits. Covers device physics, biasing, small-signal analysis, and amplifier design.

### Learning Objectives
- Understand semiconductor physics: doping, p-n junctions, carrier transport
- Analyze diode characteristics and applications (rectifiers, clippers, clampers, Zener regulators)
- Understand bipolar junction transistor (BJT) operation and biasing
- Analyze BJT amplifier circuits: small-signal models, configurations
- Understand field-effect transistor (FET) operation and biasing
- Analyze FET amplifier circuits
- Design basic transistor amplifier circuits

### Detailed Topics
- **Module 1:** Semiconductor Physics: intrinsic/extrinsic semiconductors, doping, n-type, p-type, drift, diffusion
- **Module 2:** P-N Junction Diode: depletion region, forward/reverse bias, I-V characteristics, temperature effects, breakdown
- **Module 3:** Diode Applications: half-wave/full-wave rectifiers, clipping circuits, clamping circuits, Zener diode voltage regulator
- **Module 4:** Special Diodes: LED, photodiode, Schottky diode, varactor, tunnel diode
- **Module 5:** Bipolar Junction Transistor (BJT): npn/pnp, structure, operation regions (active, cutoff, saturation), current gain (beta, alpha)
- **Module 6:** BJT Biasing: fixed bias, emitter bias, voltage divider bias, collector feedback bias, stability analysis
- **Module 7:** BJT Small-Signal Analysis: re model, hybrid-pi model, CE, CB, CC configurations, input/output impedance, voltage gain
- **Module 8:** BJT Multistage Amplifiers: cascaded amplifiers, DC coupling, frequency response, bandwidth
- **Module 9:** Field-Effect Transistors: JFET, MOSFET (enhancement/depletion), I-V characteristics, transconductance
- **Module 10:** FET Biasing and Amplifiers: fixed bias, self-bias, voltage divider bias, CS, CD, CG configurations, small-signal analysis

## Linear Algebra

### Overview
Study of vector spaces, linear transformations, matrices, and systems of linear equations. Emphasizes applications in engineering: computer graphics, signal processing, machine learning, and circuit analysis.

### Learning Objectives
- Solve systems of linear equations using Gaussian elimination and matrix methods
- Understand vector spaces, subspaces, basis, dimension, and linear independence
- Compute matrix operations, determinants, inverses, and rank
- Understand linear transformations and their matrix representations
- Compute eigenvalues, eigenvectors, and matrix diagonalization
- Apply linear algebra to engineering problems (least squares, PCA, Markov chains)

### Detailed Topics
- **Module 1:** Systems of Linear Equations: Gaussian elimination, Gauss-Jordan, row echelon form, homogeneous/non-homogeneous systems
- **Module 2:** Matrix Algebra: addition, multiplication, transpose, trace, matrix powers, inverse, partitioned matrices
- **Module 3:** Determinants: cofactor expansion, properties, Cramer's rule, applications
- **Module 4:** Vector Spaces: definition, subspaces, linear combinations, span, linear independence, basis, dimension, coordinate vectors
- **Module 5:** Linear Transformations: definition, kernel, range, rank-nullity theorem, matrix representation, change of basis
- **Module 6:** Orthogonality: inner product, norm, orthogonal vectors, Gram-Schmidt process, orthogonal projections, QR decomposition
- **Module 7:** Eigenvalues and Eigenvectors: characteristic equation, diagonalization, Cayley-Hamilton theorem, applications
- **Module 8:** Applications: least squares regression, singular value decomposition (SVD, introductory), Markov chains, image compression (PCA)

### Books

- **"Linear Algebra Done Right, 4th Edition"** by Sheldon Axler (Springer, 2023) — Theoretical, proof-based
