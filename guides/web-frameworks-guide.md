# Web Development Frameworks Guide

## Overview
This guide provides an in-depth comparison of popular web development frameworks, categorized by their primary use case (Frontend vs. Backend), to help you choose the right tool for your project.

---

## Frontend Frameworks

### React
- **Type:** Component-based UI Library.
- **Key Concepts:** Virtual DOM, Unidirectional Data Flow, JSX, Hooks.
- **Pros:** Massive ecosystem, great developer experience, highly reusable components, strong industry adoption.
- **Learning Path:** Master JavaScript (ES6+), JSX -> Understand Props/State -> Learn Hooks (useState, useEffect) -> Learn Context API/Redux/Zustand -> Learn React Router.
- **Recommended Resource:** [react.dev](https://react.dev) (Official Docs).

### Angular
- **Type:** Full-featured, opinionated framework.
- **Key Concepts:** Two-way data binding, Dependency Injection, TypeScript, RxJS.
- **Pros:** Structured, includes everything (routing, forms, HTTP client) out-of-the-box, great for large teams.
- **Learning Path:** Master TypeScript -> Learn Angular CLI -> Understand Modules/Components -> Learn Services & Dependency Injection -> Learn RxJS/Observables.
- **Recommended Resource:** [angular.dev](https://angular.dev) (Official Docs).

### Vue.js
- **Type:** Progressive, flexible framework.
- **Key Concepts:** Reactivity system, Templates, Single-File Components (SFCs).
- **Pros:** Gentle learning curve, excellent documentation, very fast.
- **Learning Path:** Master HTML/CSS/JS -> Learn Vue SFCs -> Understand Reactivity (ref/reactive) -> Learn Pinia (state management).
- **Recommended Resource:** [vuejs.org](https://vuejs.org) (Official Docs).

---

## Backend Frameworks

### Node.js (Express / NestJS)
- **Express:** Minimalist, flexible. Great for quick REST APIs.
- **NestJS:** Opinionated, TypeScript-based, uses decorators for structured code.
- **Learning Path (NestJS):** Node.js Fundamentals -> TypeScript -> NestJS Architecture (Modules, Controllers, Providers) -> TypeORM/Prisma (Database).
- **Recommended Resource:** [nestjs.com](https://nestjs.com) (Official Docs).

### Python (FastAPI / Django)
- **FastAPI:** High performance, asynchronous (async/await), auto-generated API docs (Swagger/OpenAPI). Best for modern, high-speed APIs.
- **Django:** Batteries-included, built-in admin panel, ORM, security. Best for rapid development.
- **Learning Path (FastAPI):** Python Fundamentals -> Asyncio -> FastAPI (Pydantic, Path Parameters) -> SQLModel/Prisma.
- **Recommended Resource:** [fastapi.tiangolo.com](https://fastapi.tiangolo.com) (Official Docs).

### .NET (ASP.NET Core)
- **Type:** Enterprise-grade, high-performance framework.
- **Key Features:** Strongly typed (C#), cross-platform, built-in security, excellent tooling (Visual Studio).
- **Learning Path:** C# Fundamentals -> ASP.NET Core Basics (Controllers/Minimal APIs) -> Entity Framework Core (ORM) -> Dependency Injection.
- **Recommended Resource:** [dotnet.microsoft.com](https://dotnet.microsoft.com) (Official Docs).
