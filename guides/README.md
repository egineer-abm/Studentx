# Student Guides

This directory contains guides and resources to help students succeed in their academic journey.

## Available Guides

### [Study Techniques Guide](study-techniques.md)
Effective study methods, time management strategies, and learning techniques tailored for engineering students.

### [Programming Resources Guide](programming-resources.md)
Curated list of programming tutorials, practice platforms, and project ideas for each programming language taught in the curriculum.

### [Career Preparation Guide](career-preparation.md)
Resume building, interview preparation, internship search strategies, and professional development resources.

### [Research and Publication Guide](research-guide.md)
How to conduct research, write papers, find research opportunities, and get published in academic conferences and journals.

### [Open Source Contribution Guide](open-source-guide.md)
How to get started with open source contributions, finding projects, making pull requests, and building a portfolio.

### [Exam Preparation Guide](exam-preparation.md)
Strategies for preparing for exams, managing exam stress, and performing well in both theory and practical assessments.
